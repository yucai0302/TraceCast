# TraceCast

**[English](./README.md) | 简体中文**

> 把 AI Agent 的执行过程变成可回放、可弹幕的内容 —— 让"用 AI 干活"这件事重新拥有互联网时代的活人感。

## 这是什么

TraceCast 把你用 Claude Code（或其他 Agent CLI）执行任务的完整过程 —— 规划、工具调用、报错重试、最终成功 —— 转成一条结构化的"事件时间轴"，上传到云端，围观者可以像看 B 站视频一样回放这个过程，并在关键节点上打弹幕。

核心思路不是"直播打字过程"，而是把原始 execution trace 转成**叙事化的事件节点序列**：thinking/loading 这类低信息密度片段可以跳过或压缩，报错、决策转折、成功这类高信息密度节点会被保留甚至高亮 —— 时间轴对应的是"信息密度"，不是物理时间。

## 产品形态（三个交付物）

```
tracecast/
├── capture-agent/     # 本地采集端：CLI 工具，Hook 进 Claude Code 执行流，抓取+归一化+上传事件
├── backend/           # 云端服务：事件存储、权限引擎、弹幕、自动分级、脱敏扫描
├── web/                # Web 前端：需登录，只读消费（浏览+回放+弹幕），项目管理（公开/隐藏权限）
├── sandbox-runtime/   # 沙箱服务（Phase 2）：托管项目最终交付物，供围观者直接体验
└── docs/               # 本目录：README / CLAUDE.md / SPEC.md
```

- **capture-agent**：装在开发者本机，随 Claude Code 一起跑，负责"采集"和"上传"，不做任何展示。
- **backend**：负责存储、权限判断、自动打分、弹幕挂靠逻辑，是整个产品的核心。
- **web**：面向两类人 —— 围观者（登录后只能看、只能发弹幕，不能操作项目权限）和项目所有者（额外拥有"公开/隐藏"这个项目管理权限）。
- **sandbox-runtime**（Phase 2）：把项目最终产出的可运行交付物（比如一个网页/小工具）持续托管起来。**一个公开项目对应一个沙箱实例**，所有围观者看到、体验的是同一份运行中的产品，不做逐访客隔离 —— 这样既完成了"围观过程 + 体验成果"的完整闭环，也避免了每访客开实例带来的成本失控。

## 从"看过程"到"玩成果"：完整闭环

TraceCast 的体验分两层：
1. **过程层**：回放 Agent 执行过程的事件时间轴，弹幕挂在事件节点上，讨论"这一步是怎么做出来的"。
2. **成果层**：如果这个项目产出了可运行的交付物（网页、小工具等），围观者可以在项目自带的沙箱里直接体验最终产品，弹幕继续挂在这个体验过程周围，讨论"做出来的东西怎么样"。

两层是独立的：沙箱只反映项目**当前最新**的交付物状态，不需要对应每一条历史 session（历史过程回放仍然是独立的时间轴功能）。不是每个项目都有沙箱 —— 只有产出可运行交付物的项目才会开启这一层。

## 核心设计原则（详见 SPEC.md）

1. **项目级一次性授权**：用户对某个项目开启公开后，该项目下所有后续 session 默认公开，无需逐条确认（类似 GitHub public repo 的逻辑）。
2. **事后单条可撤回**：默认公开不等于不可控 —— 所有者可以随时把某一条 session 单独设为隐藏，作为兜底安全阀。
3. **事件驱动，而非字符驱动**：采集和展示的最小单位是"事件"（规划/工具调用/报错/成功等），不是原始 token 流。
4. **弹幕挂靠在事件锚点上**，不是挂靠在绝对时间戳上 —— 保证回放时"当时的人对这一步的反应"始终对得上号。
5. **敏感信息脱敏是前提，不是可选项** —— 本地初筛 + 云端二次扫描，公开前有预览确认环节。

## MVP 范围

第一阶段只做：
- Claude Code 作为唯一采集源
- 项目级开关 + session 级隐藏
- 基础事件类型识别（plan / tool_call / error / retry / success）
- 简化版播放器（可跳过 thinking 段，弹幕挂靠在事件上）
- 邮箱登录 + 基础项目主页

暂不做（后续迭代）：多 Agent 工具源适配、实时直播模式、弹幕互动激励机制、精彩片段自动剪辑分享。

**Phase 2（MVP 之后）**：
- **沙箱托管交付物**：项目产出可运行成果后，部署到项目专属沙箱，围观者可直接体验（不只是看过程）。
- **商业化配额**：免费用户最多同时拥有 1 个"带沙箱"的公开项目；付费用户可拥有多个。这个是商业化层面的限制，不影响"过程回放 + 弹幕"这个核心免费体验 —— 配额只卡在"沙箱托管"这一层。
